The only supported public entry point is [`../PC-Full-Check.ps1`](../PC-Full-Check.ps1).

`C3B0E03C48FE797AF9C2A74778E222C3C4F6AAA1B423012B16E19165918E00D8`

This hash is retained only for historical integrity verification. The original source is deliberately unpublished. Users should not search for, request, or execute unofficial legacy copies.
